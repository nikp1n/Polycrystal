# PolyCrystal Analyzer

Приложение для анализа SEM-снимков поликристаллической поверхности: сегментация отдельных зёрен, ручное исправление масок, измерения и сохранение обработки. Используется единый алгоритм: сначала Watershed, затем предобученная MobileSAM. Выбирать метод вручную не нужно. Все изображения обрабатываются локально.

## Установка и запуск

Требуются Windows 10/11 x64, Python **3.11 или 3.12 x64**, не менее 8 ГБ ОЗУ. Видеокарта не обязательна. Интернет нужен при установке библиотек и при загрузке отсутствующих весов.

Откройте PowerShell в папке проекта:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install torch==2.5.1 torchvision==0.20.1 --index-url https://download.pytorch.org/whl/cpu
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe setup_model.py
.\.venv\Scripts\python.exe main.py
```

Если установлен Python 3.11, замените первую команду на `py -3.11 -m venv .venv`. Python 3.15 не подходит для зафиксированных зависимостей. Активация окружения не требуется. Если окружение `.venv` уже создано и библиотеки установлены, повторная установка не нужна.

Для последующих запусков используйте **run.bat** или команду:

```powershell
.\.venv\Scripts\python.exe main.py
```

При запуске через **Run в PyCharm** выберите `main.py` и тот же Python с установленными зависимостями. Если среда разработки запущена от администратора, приложение автоматически открывает окно с обычными правами рабочего стола: это необходимо для перетаскивания файлов из Проводника. Менять настройки Windows не нужно.

## Основной порядок работы

1. Нажмите **Открыть снимки** и выберите одно или несколько изображений. Можно перетащить файлы прямо на изображение, список снимков или свободную область окна. Поддерживается также перетаскивание папки: импортируются подходящие файлы из её верхнего уровня.
2. Выберите фото в списке. Оба этапа — Watershed и MobileSAM — запускаются одной кнопкой.
3. Нажмите **Сегментировать**. На CPU обработка может занимать несколько минут. Во время расчёта повторный запуск и смена исходника блокируются.
4. Проверьте границы. При необходимости включите **Редактировать зёрна** и исправьте маски.
5. Настройте исключение краевых объектов и физический масштаб, затем нажмите **Сохранить**.
6. Кнопка **Папка результатов**, расположенная рядом с **Открыть снимки**, открывает последнюю сохранённую обработку. Если в текущем сеансе ничего не сохраняли, открывается общая папка `results`.

Изображения копируются в `originals` без изменения исходного файла и разрядности. Одинаковые файлы не дублируются; при совпадении имени у разных фото к имени добавляется хеш. Каждый результат сохраняется в новую папку с именем снимка, временем и уникальным идентификатором. Несохранённые изменения можно сохранить при смене фото или закрытии.

## Светлый интерфейс и просмотр

Интерфейс использует светлую палитру независимо от темы Windows. Дополнительные параметры скрыты под кнопкой **Показать настройки**, а инструменты правки появляются только при включении **Редактировать зёрна**.

Колёсико мыши меняет масштаб. В режиме **Выбрать зерно** перетаскивание перемещает изображение. Кнопка **Вписать** возвращает весь кадр в окно. Короткий щелчок выбирает объект, **Ctrl + щелчок** добавляет или снимает выбор нескольких объектов. Выбор строки таблицы также выбирает зерно и открывает редактор.

### Промежуточные стадии

В переключателе над изображением доступны все стадии обработки:

| Стадия | Содержание |
|---|---|
| Исходный снимок | Оригинал вместе со служебной полосой |
| Предобработка | Сглаживание и локальное усиление контраста CLAHE в рабочей области |
| Карта границ | Нормированный градиент Scharr, не нейросетевая вероятность |
| Области Watershed | Первый этап: предварительные области и внутренние точки-подсказки для MobileSAM |
| Маски MobileSAM | Второй этап: маски модели до фильтра площади, дополнения и ручных изменений |
| Итоговые маски | Исправленная карта объектов с действующим фильтром анализа |
| Границы на снимке | Контуры итоговых объектов поверх оригинала |

Режимы «Исходный снимок», «Области Watershed» и «Маски MobileSAM» не зависят от фильтра краевых объектов. Переключение фильтра не требует повторной сегментации.

## Исключение краевых объектов

Флажок **Исключить краевые из анализа** действует сразу:

- краевые зёрна исчезают из обычной таблицы и итогового отображения;
- меняется счётчик **В анализе**, отдельно указывается число исключённых по краю;
- CSV измерений и аналитическая TIFF-карта при сохранении содержат только включённые зёрна.

Краем считается периметр **рабочей области**, включая нижнюю границу после удаления служебной SEM-полосы. Учитываются также объекты в пределах 2 px от края: SAM и Watershed могут оставлять тонкую нулевую рамку, хотя зерно на снимке очевидно обрезано.

Исключение обратимо: полные маски остаются в сессии. Снимите флажок, чтобы снова включить краевые зёрна. Для проверки или редактирования исключённых объектов включите **Показать исключённые объекты** над таблицей. Тогда они снова отображаются, а в таблице отмечаются причиной исключения. Этот просмотр не включает их обратно в расчёт и экспорт.

## Редактирование зёрен

Включите **Редактировать зёрна**. Правка выполняется на итоговых масках; исходные маски алгоритма остаются неизменными. Все изменения обратимы кнопкой **Отменить** или **Ctrl+Z** — до 20 действий текущей сессии.

### Добавить новое зерно

Выберите инструмент **Добавить зерно по контуру**. Щёлкните по вершинам границы и нажмите **Enter** либо завершите двойным щелчком. Также можно обвести зерно, удерживая левую кнопку. Контур замыкается автоматически. **Esc** отменяет незавершённый контур.

Новое зерно можно добавить и на место удалённого. Обведённая область получает собственный ID. Если контур захватывает соседнюю маску, её пиксели переходят новому зерну; изменение можно отменить.

### Изменить границу

Выберите одно зерно и инструмент **Изменить контур**, затем обведите правильную границу. Новый контур заменяет выбранную маску, в том числе позволяет перераспределить общую границу с соседним зерном. Если правка делит соседнюю маску на несвязные части, части получают отдельные ID с сохранением класса.

### Кисть и ластик

**Кисть** присоединяет закрашенные пиксели к выбранному зерну. Чтобы создать зерно кистью, нажмите **Снять выбор** и рисуйте по нужной области. После первого мазка новый объект остаётся выбранным: следующие мазки дополняют его. Размер кисти задаётся в пикселях исходного изображения.

**Ластик** удаляет только пиксели под мазком. Им можно изменить контур или освободить область. Если зерно разрывается на отдельные части, они получают разные ID. Пиксели за пределами рабочей области не изменяются.

### Удалить и вернуть область

Выберите зерно и нажмите **Удалить** или **Delete**. Удалённая область остаётся доступна для дальнейшей правки:

- чтобы вернуть её отдельным зерном, нажмите **Снять выбор**, выберите **Заполнить удалённую область** и щёлкните внутри неё;
- чтобы присоединить её к соседнему зерну, сначала выберите этого соседа, затем используйте **Заполнить удалённую область**;
- можно нарисовать на её месте новое зерно контуром или кистью;
- кнопка **Отменить** возвращает состояние до удаления.

Сведения об удалённых областях сохраняются в сессии, поэтому заливка работает и после сохранения и повторного открытия обработки. Для полностью открытого фона, не ограниченного масками, используйте контур или кисть: заливка всей поверхности одним объектом не выполняется.

### Объединить или разделить

Для объединения выберите соседние зёрна через **Ctrl + щелчок** и нажмите **Объединить**. Поддерживается тонкая фоновая линия между масками, оставленная водоразделом. Промежуток до двух пикселей закрывается только между выбранными объектами, чужие маски не затираются. Для более широкого промежутка можно дорисовать соединение кистью.

Для разделения выберите одно зерно, затем инструмент **Разделить зерно** и проведите линию через него за обе границы. Части получают отдельные ID; пиксели линии распределяются между ними без искусственной щели.

### Классы объектов

Кнопка **Класс объекта** назначает выбранным маскам класс **Зерно**, **Дефект** или **Исключить**. Это ручные классы: модель сама их не распознаёт. В анализ входят только объекты класса «Зерно», прошедшие фильтр края. Для возврата других объектов к редактированию включите **Показать исключённые объекты**.

После изменения масок или классов ранее вычисленные метрики качества сбрасываются. История отмены не сохраняется при переходе к другому фото; сами исправленные маски и удалённые области сохраняются.

## Настройки обработки

Откройте **Показать настройки → Алгоритм**. Новые параметры алгоритма применяются при следующем нажатии **Сегментировать**.

| Параметр | Назначение |
|---|---|
| Рабочая область | Автоматически убрать тёмную SEM-полосу, использовать весь кадр или задать высоту вручную |
| Высота | Число верхних строк кадра, участвующих в обработке |
| Минимальная площадь | Удаление малых автоматических компонент в px²; слишком большой порог удаляет реальные мелкие зёрна |
| Сглаживание σ | Подготовка контрольного изображения и рельефа Watershed |
| Глубина маркеров | Выраженность локальных максимумов первого этапа Watershed; меньше — больше областей и подсказок SAM, но выше риск дробления |
| Детализация мелких зёрен | При плотной структуре дополнительный анализ четырёх перекрывающихся фрагментов |
| Дополнить маски по Watershed | Заполнить пропуски в подтверждённых SAM объектах в пределах предварительных областей первого этапа |
| Порог predicted IoU | Фильтр внутренней оценки SAM; снижение увеличивает полноту и риск ложных масок |
| Стабильность SAM | Устойчивость маски к изменению порога |

Автоматическая обрезка рассчитана на тёмную служебную полосу. Если она определена неверно, задайте высоту вручную. Масштабную линейку измеряют на исходном кадре, даже если она исключена из сегментации.

Обработка всегда идёт в одном порядке:

1. Сглаживание, CLAHE и маркерный Watershed выделяют предварительные области.
2. Для каждой области выбирается внутренняя точка по максимуму расстояния до границы. Эти точки передаются MobileSAM как положительные подсказки. При плотной структуре модель дополнительно анализирует перекрывающиеся фрагменты с подсказками из соответствующих областей Watershed.
3. MobileSAM получает исходную текстуру рабочей области и строит маски. Перекрытия разрешаются по вложенности, выделяются связные компоненты и удаляются компоненты ниже минимальной площади.
4. При включённом дополнении неполные маски заполняются в пределах уже рассчитанных областей Watershed, если в области есть достаточное подтверждение SAM. Области без подтверждения модели не превращаются автоматически в зёрна. Очень тёмные пиксели не закрашиваются. Повторного запуска Watershed после модели нет.
5. Рассчитываются характеристики, применяется фильтр анализа. Большие или вытянутые зёрна не удаляются по отклонению формы или размера от среднего.

Watershed и MobileSAM не являются альтернативами: второй этап зависит от результата первого. Промежуточные области, маски модели и итог доступны отдельно. Если веса модели отсутствуют или MobileSAM завершилась ошибкой, обработка сообщает об ошибке и не выдаёт один Watershed за общий результат.

## Физический масштаб

Откройте **Показать настройки → Масштаб**. Значение **Единиц на пиксель = 0** означает px и px². Можно ввести размер пикселя вручную либо нажать **Измерить линейку на снимке**, провести отрезок между её концами и ввести физическую длину.

При единице µm подпись «200 nm» вводится как **0.2**. Масштаб равен физической длине / длине отрезка в пикселях. Длины и координаты умножаются на масштаб, площади — на его квадрат. Предполагаются квадратные пиксели. Начало координат — левый верхний угол, X вправо, Y вниз.

Смена масштаба сразу пересчитывает таблицу. При открытии другого фото масштаб сбрасывается; при восстановлении сохранённой обработки возвращается её калибровка.

## Измерения и качество

Таблица показывает ID, класс, включение в анализ, площадь, периметр Крофтона, максимальный диаметр Фере, координаты центра и эксцентриситет. В CSV дополнительно записываются большая и малая оси эллипса вторых моментов, эквивалентный диаметр, показатели границы и признаки касания края. Оси эллипса не равны буквальной длине внешнего контура. Показатель однородности границы равен `1/(1+CV)` яркости её пикселей и сам по себе не доказывает правильность сегментации.

На вкладке **Оценка качества** можно загрузить независимую эталонную разметку TIFF или NPY: двумерный целочисленный массив размера исходного кадра, 0 — фон, каждый положительный ID — отдельное зерно. Цветное изображение и бинарная маска всей поверхности не заменяют объектную разметку.

Рассчитываются foreground IoU/Dice, Precision/Recall/F1 объектов при IoU ≥ 0.5, средний IoU совпавших объектов, PQ и Boundary F1 с допуском 2 px. Оценка выполняется по полной карте рабочей области, включая края, чтобы фильтр анализа не скрывал ошибки алгоритма. Без эталона метрики не измеряются. Predicted IoU SAM — оценка самой модели, а не экспериментальная точность.

## Пакетная обработка

Откройте **Показать настройки → Алгоритм → Обработать весь список**. Все фото списка последовательно обрабатываются общим алгоритмом Watershed → MobileSAM с сохранением в отдельные папки `results`. Требуются автоматическая рабочая область и масштаб 0: физическую калибровку разных кадров нужно выполнять отдельно.

Кнопка **Остановить пакет** появляется во время работы. Остановка происходит после текущего снимка, готовые результаты сохраняются. Ошибка одного файла не прерывает остальные. Открытая ручная обработка не подменяется пакетным результатом.

## Сохранение и продолжение работы

Кнопка **Сохранить** создаёт новую папку результата:

| Файл | Содержимое |
|---|---|
| 01_original.png … 06_overlay.png | Шесть обязательных стадий; итоговые маски и наложение учитывают фильтр анализа |
| watershed_labels.tif, 03a_watershed.png | Предварительные области первого этапа |
| raw_labels.tif | Маски MobileSAM до постобработки |
| labels.tif | Полная исправленная карта, включая обратимо исключённые объекты |
| analysis_labels.tif | Карта только включённых в анализ зёрен |
| classes.tif | 0 — фон, 1 — зерно, 2 — дефект, 3 — исключить |
| grains.csv | Измерения включённых зёрен; UTF-8 BOM, разделитель `;`, десятичная точка |
| summary.json | Исходник, SHA-256, параметры, калибровка, классы, число включённых и исключённых объектов, метрики при наличии |
| session.npz | Полные маски, удалённые области и промежуточные массивы для продолжения правки |
| model_confidence.npy | Внутренние оценки исходных масок SAM, если применялась модель |

PNG оригинала — экранная копия; исходная разрядность сохраняется в `originals`. Карта уверенности относится к автоматическому выводу и не пересчитывается после ручной правки.

Чтобы продолжить работу, откройте соответствующее исходное фото, затем **Файл → Открыть сохранённую обработку** и выберите `session.npz`. Рядом должен находиться `summary.json`. Проверяется хеш фото, поэтому результат другого исходника не применяется. Возвращаются маски, классы, калибровка и удалённые области. Для переноса на другой компьютер сохраните исходное фото и всю папку результата.

Горячие клавиши: **Ctrl+O** — открыть; **Ctrl+S** — сохранить; **Ctrl+Z** — отменить правку; **Delete** — удалить выбранные объекты; **Enter** — завершить контур; **Esc** — отменить незавершённый контур.

## Алгоритм и ограничения

Блок-схема представлена в `FLOWCHART.svg`. Этапы: проверка и импорт исходника → выделение рабочей области → контрольная предобработка и градиент → Watershed → MobileSAM по подсказкам Watershed → постобработка и уточнение → измерения и фильтр анализа → визуальная проверка и ручная правка → оценка по эталону при наличии → экспорт.

Универсальная MobileSAM не дообучена на этой SEM-серии. Слабые границы могут приводить к слияниям, внутренний контраст — к дроблению, а мелкие зёрна — к пропускам. На Lu3+ особенно важно проверить слияния. Поэтому автоматический результат нужно сопоставлять с оригиналом и при необходимости редактировать. Наличие предобученной модели соответствует требуемому типу подхода повышенного уровня; итоговый балл зависит также от качества на новых снимках и защиты.

Поддерживаются серые и RGB/RGBA PNG, JPEG, BMP, двумерные TIFF, в том числе 16-битные. TIFF-стеки необходимо разделить на отдельные кадры. При нормировании и показе оригинальные массивы не перезаписываются.

## Модель и лицензия

Использована официальная [MobileSAM](https://github.com/ChaoningZhang/MobileSAM), TinyViT, ревизия `f706ad9c4eb7f219c00d9050e46328518ffb65d2`. Авторы — Chaoning Zhang и соавторы, [статья](https://arxiv.org/abs/2306.14289). Код и веса распространяются по Apache License 2.0; текст лицензии находится в `models/LICENSE-MobileSAM.txt`.

Веса `models/mobile_sam.pt` проверяются по SHA-256:
`6dbb90523a35330fedd7f1d3dfc66f995213d81b29a5ca8108dbcdd4e37d6c2f`.
При отсутствии файла `setup_model.py` получает официальную модель. Во время сегментации загрузка из сети не выполняется; используются проверенные локальные веса и `torch.load(weights_only=True)`.
